# oxirpc-reflect — gRPC server reflection (v1 + v1alpha) for OxiRPC

[![Crates.io](https://img.shields.io/crates/v/oxirpc-reflect.svg)](https://crates.io/crates/oxirpc-reflect)
[![License](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

`oxirpc-reflect` implements the **gRPC Server Reflection protocol** (`grpc.reflection.v1` and the legacy `grpc.reflection.v1alpha`) for the OxiRPC stack. Server reflection lets tooling such as `grpcurl`, Postman, or `grpc_cli` discover the services, methods, and message types a running server exposes — without a local copy of the `.proto` files — by querying the server over the standard bidi-streaming `ServerReflectionInfo` RPC.

The crate offers **two implementations** behind one ergonomic API. The first wraps [`tonic_reflection`]'s `server::Builder`, accepting encoded `FileDescriptorSet` bytes (the output of `prost::Message::encode_to_vec` on a `prost_types::FileDescriptorSet`) and returning a mountable `ServerReflectionServer`. The second is a fully **native** implementation ([`NativeReflectionServiceV1`] / [`NativeReflectionServiceV1Alpha`]) that speaks the reflection wire protocol directly through OxiRPC's own native server wire helpers — no `tonic_reflection` runtime dependency, with optional gRPC message compression via OxiARC. Both paths are 100% Pure Rust (`#![forbid(unsafe_code)]`); the crate is backed by tonic 0.14 only on the `build`/`reflection_service_*` path.

## Installation

```toml
[dependencies]
oxirpc-reflect = "0.2.0"
```

With optional features:

```toml
[dependencies]
# Enable the richer oxiproto-reflect DescriptorPool backend for the native service
oxirpc-reflect = { version = "0.2.0", features = ["oxiproto"] }

# Enable gRPC message compression on the native reflection service
oxirpc-reflect = { version = "0.2.0", features = ["gzip", "zstd"] }
```

## Quick Start

### Static descriptor bytes (tonic-reflection path)

```rust,no_run
use oxirpc_reflect::reflection_service_from_static;

# fn get_fds_bytes() -> &'static [u8] { &[] }
fn main() -> Result<(), oxirpc_reflect::ReflectError> {
    // FDS bytes typically come from `include_bytes!("descriptor.bin")`
    // generated by oxirpc-build / tonic-prost-build.
    let svc = reflection_service_from_static(get_fds_bytes())?;
    // tonic::transport::Server::builder().add_service(svc).serve(addr).await?;
    Ok(())
}
```

### Native service (no tonic-reflection runtime)

```rust,no_run
use oxirpc_reflect::ReflectionBuilder;

let (v1, _v1alpha) = ReflectionBuilder::new()
    .register_file_descriptor_set(vec![])   // your encoded FDS bytes
    .build_native();
// Mount v1 via tonic::transport::Server::builder().add_service(v1).
```

### Combined v1 + v1alpha builder

```rust,no_run
use oxirpc_reflect::ReflectionBuilder;

# fn run() -> Result<(), oxirpc_reflect::ReflectError> {
#[allow(deprecated)]
let services = ReflectionBuilder::new()
    .register_file_descriptor_set(vec![])   // your encoded FDS bytes
    .include_v1alpha(true)
    .build()?;
// Mount services.v1 and (optionally) services.v1alpha.
# Ok(())
# }
```

### Pre-decoded descriptor pool

```rust,no_run
use oxirpc_reflect::{DescriptorPoolBuilder, reflection_service_from_pool};

# fn run() -> Result<(), oxirpc_reflect::ReflectError> {
let pool = DescriptorPoolBuilder::new()
    .register(prost_types::FileDescriptorSet { file: vec![] })
    .build();
let svc = reflection_service_from_pool(pool)?;
# Ok(())
# }
```

## API Overview

### Free functions (tonic-reflection backed)

Each returns a `ServerReflectionServer<impl ServerReflection>` (or the v1alpha equivalent) that mounts on a tonic server via `add_service`.

| Function | Description |
|----------|-------------|
| `reflection_service_from_static(&'static [u8])` | Build a v1 service from `'static` encoded FDS bytes (e.g. `include_bytes!`). No decode, no leak. |
| `reflection_service_owned(Vec<u8>)` | Build a v1 service from owned FDS bytes; decoded immediately, no `'static` bound. |
| `reflection_service_v1alpha_from_static(&'static [u8])` | Build a **v1alpha** service from `'static` encoded FDS bytes (legacy clients). |
| `reflection_service_from_pool(DescriptorPool)` | Build a v1 service from a pre-built [`DescriptorPool`]; no byte decoding. |

### `DescriptorPool`

A collection of pre-decoded `FileDescriptorSet` values ready for reflection registration. Construct via [`DescriptorPoolBuilder`] or `decode`. Implements `Debug + Clone`.

| Method | Description |
|--------|-------------|
| `file_descriptor_sets(&self)` | Borrow the raw `&[FileDescriptorSet]` backing the pool |
| `add_service(&mut self, fds)` | Append a `FileDescriptorSet` (dynamic runtime registration) |
| `remove_service(&mut self, name) -> bool` | Remove single-service FDS entries matching `name`; returns whether any were removed |
| `list_services(&self) -> Vec<String>` | All service names across every registered FDS |
| `encode(&self) -> Vec<u8>` | Merge all descriptors into one proto-encoded `FileDescriptorSet` blob |
| `decode(&[u8]) -> Result<Self, ReflectError>` | Decode a proto-binary blob into a pool |
| `extension_numbers(&self, message_name) -> Vec<i32>` | Top-level extension field numbers targeting `message_name` |
| `find_file_by_name(&self, name)` | First `FileDescriptorProto` whose `name` field equals `name` |
| `find_file_containing_symbol(&self, symbol)` | First file defining the fully-qualified `symbol` (messages incl. nested, top-level enums, services, methods) |
| `find_file_containing_extension(&self, containing_type, number)` | First file defining extension `number` on `containing_type` |

### `DescriptorPoolBuilder`

Builder for [`DescriptorPool`]; prefer it over [`ReflectionBuilder`] when you already hold decoded `FileDescriptorSet` values. Implements `Debug + Default`.

| Method | Description |
|--------|-------------|
| `new()` | Create an empty builder |
| `register(self, fds)` | Register a pre-decoded `FileDescriptorSet` |
| `register_bytes(self, &[u8]) -> Result<Self, ReflectError>` | Register from proto-binary bytes, decoding immediately |
| `build(self) -> DescriptorPool` | Finalize the pool |

### `ReflectionBuilder`

A combined builder accepting multiple FDS byte slices (owned or shared) and producing v1 (and optionally v1alpha) services, or the native services, in a single call. Implements `Debug + Default`.

| Method | Description |
|--------|-------------|
| `new()` | Create a new, empty builder |
| `register_file_descriptor_set(self, impl Into<Vec<u8>>)` | Register owned encoded FDS bytes (stored in `Arc<[u8]>`) |
| `register_encoded_file_descriptor_set(self, Arc<[u8]>)` | Register a pre-shared `Arc<[u8]>` of encoded FDS bytes |
| `register_pool(self, DescriptorPool)` | Register a pre-built [`DescriptorPool`] alongside byte registrations |
| `register_oxiproto_pool(self, Arc<DescriptorPool>)` | **(`oxiproto`)** Use an `oxiproto_reflect::DescriptorPool` as the native backend |
| `register_service_named::<S: NamedService>(self)` | Allowlist a service by `S::NAME`; only matching descriptors are exposed |
| `include_v1alpha(self, bool)` | Also build a v1alpha service (default `false`) |
| `build_native(self) -> (NativeReflectionServiceV1, NativeReflectionServiceV1Alpha)` | Build both native services backed by the same pool |
| `build_native_v1(self) -> NativeReflectionServiceV1` | Build only the native v1 service |
| `build(self) -> Result<ReflectionServices, ReflectError>` | **Deprecated** — tonic-reflection backed v1 (+ optional v1alpha). Prefer the native builders. |

### `ReflectionServices<V1, VA>`

The result of the deprecated [`ReflectionBuilder::build`]: a v1 service plus an optional v1alpha service. The type parameters are opaque (concrete types are internal to `tonic_reflection`).

| Field | Type | Description |
|-------|------|-------------|
| `v1` | `ServerReflectionServer<V1>` | gRPC reflection v1 service |
| `v1alpha` | `Option<v1alpha::ServerReflectionServer<VA>>` | v1alpha service, present when `include_v1alpha(true)` |

### Native services

Both are `tower::Service` + `tonic::server::NamedService` implementations of the bidi-streaming `ServerReflectionInfo` RPC, backed by a shared descriptor pool, with `grpc-accept-encoding` negotiation when compression features are enabled.

| Type | `NamedService::NAME` | Description |
|------|----------------------|-------------|
| `NativeReflectionServiceV1` | `grpc.reflection.v1.ServerReflection` | Stable v1 reflection service |
| `NativeReflectionServiceV1Alpha` | `grpc.reflection.v1alpha.ServerReflection` | Legacy v1alpha reflection service |

### `service` module

Lower-level native service plumbing, re-exported in part at the crate root.

| Item | Description |
|------|-------------|
| `NativeReflectionService` | Inner bidi-streaming service shared by the v1/v1alpha wrappers; `Clone` |
| `NativeReflectionService::new(Arc<DescriptorPool>, ReflectVersion)` | Construct backed by the native pool |
| `NativeReflectionService::with_oxiproto_pool(...)` | **(`oxiproto`)** Construct backed by an `oxiproto_reflect::DescriptorPool` |
| `NativeReflectionService::version(&self) -> ReflectVersion` | The protocol version this service speaks |
| `NativeReflectionService::handle_request(&self, req) -> ServerReflectionResponse` | Handle a single reflection request synchronously |
| `ReflectVersion` | `V1` or `V1Alpha` protocol-version tag (`Copy + Eq`) |

### `proto` module — native reflection wire types

Hand-authored `prost`-derived structs matching the official `grpc.reflection.v1` proto, suitable for embedding in a custom reflection server. All derive `Clone + prost::Message` (or `prost::Oneof`).

| Type | Corresponds to |
|------|----------------|
| `ServerReflectionRequest` | `grpc.reflection.v1.ServerReflectionRequest` (fields `host`, `message_request`) |
| `server_reflection_request::MessageRequest` | The request oneof: `FileByFilename`, `FileContainingSymbol`, `FileContainingExtension`, `AllExtensionNumbersOfType`, `ListServices` |
| `ExtensionRequest` | `grpc.reflection.v1.ExtensionRequest` (`containing_type`, `extension_number`) |
| `ServerReflectionResponse` | `grpc.reflection.v1.ServerReflectionResponse` (`valid_host`, `original_request`, `message_response`) |
| `server_reflection_response::MessageResponse` | The response oneof: `FileDescriptorResponse`, `AllExtensionNumbersResponse`, `ListServicesResponse`, `ErrorResponse` |
| `FileDescriptorResponse` | Serialized `FileDescriptorProto` bytes (`file_descriptor_proto: Vec<Vec<u8>>`) |
| `ExtensionNumberResponse` | `base_type_name` + `extension_number: Vec<i32>` |
| `ListServiceResponse` | `service: Vec<ServiceResponse>` |
| `ServiceResponse` | A single `name` entry |
| `ErrorResponse` | `error_code` + `error_message`; `ErrorResponse::not_found(name)` builds a `NOT_FOUND` (5) error |

### Re-exports from `tonic_reflection`

For convenience the crate re-exports `tonic_reflection::server::v1::{ServerReflection, ServerReflectionServer}` at the crate root.

## Feature Flags

| Feature | Default | Description |
|---------|---------|-------------|
| `gzip` | off | Enable gzip message compression on the native service via `oxirpc-core/gzip` (OxiARC DEFLATE) |
| `zstd` | off | Enable Zstandard message compression via `oxirpc-core/zstd` (OxiARC) |
| `oxiproto` | off | Enable the `oxiproto-reflect` `DescriptorPool` backend for the native service (richer prost-reflect pool) |

All features are off by default and keep the crate 100% Pure Rust.

## Error Variants

`ReflectError` is `#[non_exhaustive]` and implements `std::error::Error` (with `source`) and `Display`.

| Variant | Description |
|---------|-------------|
| `Build(tonic_reflection::server::Error)` | The `tonic_reflection` builder rejected the descriptors (e.g. malformed FDS, missing file name) |
| `Decode(prost::DecodeError)` | A `prost` decode error while parsing a `FileDescriptorSet` from bytes |

# Security Policy

## Supported Versions

OxiRPC is pre-1.0 software under active development. Security fixes are provided
only for the **latest published `0.x` release line**. Older `0.x` releases do not
receive backported patches — please upgrade to the most recent version before
reporting an issue.

| Version        | Supported          |
|----------------|--------------------|
| Latest `0.x`   | :white_check_mark: |
| Older releases | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
pull requests, or discussions.**

Instead, report them privately by email to:

- **Maintainer:** COOLJAPAN OU (Team Kitasan)
- **Contact:** info@kitasan.io

Please include, where possible:

- a description of the vulnerability and its impact;
- the affected crate(s), version(s), and feature flags;
- steps to reproduce or a minimal proof-of-concept;
- any suggested mitigation.

## Disclosure Process

- We aim to acknowledge new reports within a few business days.
- Reports are triaged privately. We will work with you to understand and
  validate the issue and to prepare a fix.
- A fixed release and an advisory are published once a patch is available; we
  will credit reporters who wish to be acknowledged.

Thank you for helping keep OxiRPC and its users safe.
